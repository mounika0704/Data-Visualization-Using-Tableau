# Data Visualization Using Tableau

A collection of Tableau workbooks demonstrating data visualization and dashboard design across different domains.

## Files Included

| File | Description |
| `Category.twb` | Visualization of category-wise data |
| `Customer.twb` | Customer data analysis and dashboard |
| `Feedback.twb` | Feedback data visualization |
| `Patient.twb` | Patient data analysis dashboard |
| `Student.twb` | Student data visualization |
| `Super Store.twb` | Superstore sales/performance dashboard |

## Tools Used

- Tableau Desktop / Tableau Public

## Topics Covered

- Interactive dashboards
- Data visualization best practices
- Filters, parameters, and calculated fields
- Charts, graphs, and KPI visuals
- Storytelling with data

## How to Use

1. Clone or download this repository.
2. Open the `.twb` files using [Tableau Desktop](https://www.tableau.com/products/desktop) or [Tableau Public](https://public.tableau.com/).
3. Explore the dashboards and visualizations.

> **Note:** `.twb` files reference data sources — you may need the original data files/connections for the visuals to load correctly.

## About

This repository showcases practical data visualization skills using Tableau across various real-world datasets like customers, patients, students, feedback, and retail sales.
